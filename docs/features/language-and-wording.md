# Language and wording

- **Language**: English, Hong Kong Cantonese, or both side by side.
- **Funny level**: 1 to 5 changes how playful the wording around a result is. Facts and safety warnings never change.
- **Personal wording**: drop a JSON file anywhere in the app, or choose one in Settings, shaped like `{"version": 1, "entries": {"Deploy": "Ship"}}`. It is checked as a whole and applied all at once or not at all. **Clear** restores the original words.
