# Language and wording

- **Language**: English, Hong Kong Cantonese, or both side by side.
- **Funny level**: 1 to 5 changes how playful the wording around a result is. Facts and safety warnings never change.
- **Personal wording**: drop a JSON file anywhere in the app, or choose one in Settings, shaped like `{"version": 1, "entries": {"Deploy": "Ship"}}`. It is checked as a whole and applied all at once or not at all. **Clear** restores the original words.

## Voices

With **Read status aloud** on, choose a separate installed voice for English and for Cantonese, and set pitch and speed. **Try this voice** plays a short sample. When no voice for a language is installed, the setting says so instead of guessing.

## Wording celebration

Dropping a valid wording file plays a short celebration with a tada sound. Reduced motion, calm mode and school mode show a quiet badge instead, and sounds follow the Action sounds setting.
