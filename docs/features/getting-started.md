# Getting started

Open the app. Setup checks this computer for AWS CLI v2.22 or later and Docker, and lists the AWS CLI profiles on your Windows account.

- If a tool is missing, press **Install missing tools**. See [one-click setup](one-click-setup).
- Pick a profile and press **Continue** to sign in. See [signing in](signing-in).
- Then start a deployment from the New deployment button. See [deploying](deploying).

Deployments create real AWS resources that cost money until you delete them in AWS.
