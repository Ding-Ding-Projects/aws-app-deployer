# Settings

Every setting has an info button directly above its control, in the same place on every row. Hover or focus it for a tooltip; press it (or Enter or Space) for the full explanation: what the setting does, whether the value came from your settings file or the built-in default, and a practice run that never changes the real value. Closing the explanation returns focus to the button that opened it. The button is drawn small but answers to a 44 by 44 pixel area, so it is easy to hit with a finger or a shaky hand.

Search settings from the top of the Settings screen. Right-click a setting for **Reset to default**.

## Colour picker

Press **Pick** next to the custom colour to open the colour picker: a saturation and brightness square (drag, or use the arrow keys), a hue slider and an opacity slider. It reads and writes hex with alpha, `rgb()`, `rgba()`, `hsl()`, `hsla()` and colour names, and shows the WCAG contrast ratio against the page background with a plain verdict.

The app keeps the hue you pick and chooses a readable shade of it for each theme: buttons, links and the selection use a darker shade in the light theme and a lighter one in the dark theme, so a pale pick never turns into pale text. The colour you picked is still the one saved and shown on the swatch.

## Funny level on every message

Every notification is styled by the funny level for its language, errors and warnings included. The facts in the message never change. School mode turns the styling off.
