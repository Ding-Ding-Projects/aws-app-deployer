# Settings

Every setting has an info button above its control. It explains what the setting does, says whether the value came from your settings file or the built-in default, and offers a practice run that never changes the real value.

Search settings from the top of the Settings screen. Right-click a setting for **Reset to default**.

## Colour picker

Press **Pick** next to the custom colour to open the colour picker: a saturation and brightness square (drag, or use the arrow keys), a hue slider and an opacity slider. It reads and writes hex with alpha, `rgb()`, `rgba()`, `hsl()`, `hsla()` and colour names, and shows the WCAG contrast ratio against the page background with a plain verdict.

## Funny level on every message

Every notification is styled by the funny level for its language, errors and warnings included. The facts in the message never change. School mode turns the styling off.
