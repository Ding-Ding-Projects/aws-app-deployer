# Deployment charts

The Deployments screen shows two charts built only from records on this computer:

- **Deployment time:** minutes for the last 12 deployments that recorded timing. Stopped deployments show as amber points. Hover a point for its name and time.
- **Outcomes:** healthy and stopped deployments for each of the last 7 days.

Records made before timing was added have no duration, and none is guessed. **Table view** shows the same numbers as plain tables for screen readers and copying. With reduced motion on, the line appears without drawing in.
