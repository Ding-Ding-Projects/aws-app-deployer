# Tabs

The Workspace tab holds the main screens. Ordinary navigation never opens tabs. Press **New tab** to open a utility tab from the catalog: local history, docs, changelog, settings, help or accounts. Search the catalog with or without regex. Right-click a tab to close it or close the others.

When many tabs are open, **New tab** stays pinned at the right end of the strip, long tab names shorten with an ellipsis (hover for the full name), and the mouse wheel scrolls the strip sideways. The active tab is kept in view. While a utility tab is active the navigation rail marks nothing; pressing a rail item returns to the Workspace tab.
