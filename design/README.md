# Design handoff

This directory holds the designer's source files and implementation handoff.

Primary journeys: connect an AWS account in the browser and return to the desktop application; select a project; configure a deployment; follow build and deployment progress; inspect health and rollback status.

Use ordinary technical terminology. Do not bundle account identifiers, credentials, or private instruction content.

The design handoff has been delivered: read [HANDOFF.md](HANDOFF.md) and [DESIGN.md](DESIGN.md). Artboards are in `artboards/`, prototype renders in `frames/`.
