How it runs
npm run sweep:appOpens every route of the built app from a fresh profile, settles motion, runs the checks, then walks the keyboard with Tab. Exits with an error on any finding.
npm run sweep:siteOpens the landing page and each overlay in Chromium. The two GitHub lookups answer with sample data, so a rate limit is never a finding.
ruleWhat counts: axe-core 4.10 WCAG 2.2 AA and best practice, clipped, off-screen and overlapping text, console errors, blocked requests, and focus with no ring, no name, on something hidden, or outside an open dialog.
blockRelease rule: zero findings, or no release. A fix lands in the shared token or component, never in one screen.
visibility_offNot checked here: the real Windows caption buttons and Snap layouts need a Windows desktop, and axe checks names and roles, not what a screen reader actually says.
