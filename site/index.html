QUESTIONS

Before you deploy.

Does it cost money?

The app is free. AWS charges for the load balancer, Fargate tasks, image storage, logs and data transfer until you delete the deployment.

Will closing the app delete my site?

No. Infrastructure is only removed through a separate, explicit delete flow.

Do visitors need an AWS account?

No. The link is public. Your own app's sign-in, if it has one, keeps working.

Does it support multi-service Compose?

Not yet. This version deploys one Compose service and tells you before anything is created if others would be skipped.

Can several people use it?

Yes. Each Windows user signs in with their own AWS profile; nothing is shared through a server of ours.

What if a deploy breaks?

Known problems are retried or repaired automatically. A failed release rolls back, and the app names the one thing that needs you.

Ship your container today.Windows 10 or 11 and an AWS account. The app installs the rest.
